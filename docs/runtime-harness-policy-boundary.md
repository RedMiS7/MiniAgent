# Runtime 与 Harness 策略边界修正

此前阶段拆分将审批、中断、重试和错误恢复的任务及验收放在 Runtime，未在 Harness 中体现策略职责，与约定不一致。

本次将这些策略及对应验收移入 P6 Harness。P5 Runtime 管理 Run 的状态、结果、限制、取消和清理，为上层提供事实并执行控制指令。中断后的取消与清理由 Runtime 落实，是否中断、重试或恢复由 Harness 决定。

同步修正阶段拆分说明，P8 的 Human-in-the-loop 改为 P6 基础审批之外的人工干预扩展，避免重复规划。阶段编号和完成状态保持不变。

验证：核对 P5/P6 的任务与验收归属、P8 的审批依赖，并检查 Git 差异格式。本次为纯文档修正，未运行功能测试或实现新能力。
