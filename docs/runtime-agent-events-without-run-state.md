# 用 AgentEvent 表达运行过程

## 问题与决定

用户要求完整消费 AgentEvent，不再重复设计 RunState。现有 AgentStarted、AgentProgress、AgentCompleted、AgentFailed 和 AgentCancelled 已经表达运行生命周期，公开状态类型及查询属性没有必要。

本次移除 RunState 类型、公共导出和 AgentRuntime.state。未用另一个状态枚举、字符串属性或状态机替代。

## 保留的职责

- 调用方完整消费 run.events() 中的 AgentEvent，判断开始、进度及成功、失败或取消。终态事件后继续消费到流结束，保留原有异常传播。
- RunResult 仅保存收尾后的结果、结束原因、成功历史及错误摘要；status 只分类最终结果，不表达待启动或运行中。
- Runtime 内部保留单次启动、取消请求、消费协调和清理所需的标记，这些是执行控制细节，不公开为状态接口。
- await runtime.run(...) 仍内部完整消费事件并返回结果。
- 提前退出的资源清理继续保留。异常离开或启动前取消没有完整事件流时，可读取最终结果，但不据此增加另一套运行状态接口。

## 改动与取舍

移除公开类型及属性，更新调用测试，纠正文档示例和路线图中的旧状态设计。原先使用 state 的结束断言改为检查 RunResult；收尾中的断言检查 result 尚未发布。

新增按完整事件流验收的测试，覆盖纯文本成功、模型非成功结束、步数上限、工具失败后完成、模型异常和主动取消。测试以事件顺序与唯一终态判断过程，不依赖状态查询。另验证公开模块及 Runtime 不再提供这套接口。

这属于 P5 的接口精简，不增加运行能力，不推进 Harness 或双重故障处理。

## 验证与限制

先验证公开接口回归测试因旧 RunState 导出存在而失败，再移除接口：

- Runtime 相关 34 项测试通过；结果契约 8 项测试通过。
- python -m unittest discover -s tests -q：全部 144 项离线测试通过。
- 未使用真实模型接口。

这是一次公共接口移除，外部调用方需从 runtime.state 迁移到完整消费 AgentEvent；仅需最终结果的调用方继续使用 RunResult。执行故障与清理故障同时发生的交付约定以及 P5 整体验收仍待完成。
