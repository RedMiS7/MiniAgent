# P3 单 Agent 数据结构范围修正

## 为什么修正

此前将统一数据结构误解为多个 Agent 的任务交接，并用两个假 Agent 作为验收条件，偏离了单 Agent 项目的目标。
P3 的作用是为同一个 Agent 内的模型调用、工具执行和 harness 提供一致的数据契约，使组件可以协作、替换和复用。

## 本次调整

删除 Agent 间任务交接和双 Agent 验收，改为单 Agent 一次调用链的数据传递验证。
明确 AgentEvent、LLMEvent 和 ToolEvent 各自表达运行、模型和工具的过程，保留必要的关联与校验。
移除未经需求支持的统一序列化与版本机制任务；已有模型续接状态仍按原协议保留。
P3 用模拟数据验证类型与转换，实际执行循环仍由 P4 实现，避免阶段互相依赖。

## 验证与限制

检查路线图已明确单 Agent 范围，P3 不再要求多个 Agent 通信，其他阶段和完成状态保持不变。
本次仅修正文档并检查格式，未修改代码或运行功能测试。
