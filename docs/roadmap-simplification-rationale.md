# 路线图精简说明

## 为什么调整

原路线图在任务条目中混入较多字段、实现流程和边界细节，难以快速看出每阶段的目标。
本次将任务压缩为简短描述，并为 P0 至 P7 统一补充验收标准，方便按结果判断阶段是否完成。

## 方案与取舍

保留阶段顺序、已有完成状态，以及模型扩展、工具扩展和 harness 复用三个目标。
任务条目说明要做什么，验收标准说明做到什么程度；具体字段与实现设计留给后续小任务的 docs 文档。
关键的通信关联、停止控制、授权和离线验证要求仍保留，避免精简后失去判断依据。
P7 保持按需逐项验收，避免把探索方向全部变为最小版要求。
